# Experiment execution

The experiment runner must be given a fixed model, parameter vector, observation grid, reference provenance, solver matrix, noise seed, and budget. Each JSON report is a record of one configuration matrix, not a proof of a method's superiority.

The first executable slice is the oscillator CLI. Extend the same protocol to FitzHugh–Nagumo, Lotka–Volterra, Lorenz, and Robertson only after their reference convergence is checked. Store generated reports under ignored `results/` and commit only small, intentionally selected fixtures.
