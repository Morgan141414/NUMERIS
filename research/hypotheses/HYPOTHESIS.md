# Falsifiable hypothesis

For a declared scientific target and fixed computational budget, a goal-oriented allocation policy can reduce target error relative to a correctly tuned trajectory-error baseline on at least one defined class of parameterized ODE inference problems.

## Falsification conditions

The hypothesis is not supported if the policy is mathematically equivalent to an existing method, does not beat tuned baselines within uncertainty, only wins on a hand-picked system, costs more than the target benefit, or reports unreliable error estimates. A mixed result must be reported as mixed, with the applicability class narrowed.

## Primary endpoint

Target error at matched total RHS evaluations. Parameter RMSE and likelihood error are primary deterministic endpoints; posterior distances are secondary until a controlled Bayesian protocol exists.
