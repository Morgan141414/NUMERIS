# Literature review ledger

This directory is intentionally a research ledger, not a claim of completed literature review. Before naming a contribution, record for every related method: objective, error estimator, control variable, budget model, assumptions, implementation, benchmark overlap, and exact distinction from NUMERIS.

Required comparison families include adaptive ODE control, adjoint/goal-oriented estimation, probabilistic numerical ODE solvers, likelihood-aware inference, Bayesian inverse problems, and existing implementations such as SciPy/SUNDIALS/SciML and DALTON where reproducible conditions are available.
